## Installation

Install **Presence.apk** over the existing app, then reopen Presence. This build retains the existing signing identity for compatible in-place updates. The current updater handles installation; the centered section appears after updating.

Update downloads include only three short highlights. Full documentation stays on GitHub. Existing checksum, package and signing verification remain unchanged.

Android compilation, unit tests, update artifact checks and APK package/signature/asset verification are performed before publication. Real-phone visual and installation checks still require device testing.

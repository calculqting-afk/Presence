# Presence v1.8.7

Updates since v1.8.6:

- Secure administrator password resets with one-time temporary passwords and a required password change at next login.
- Forgot-password assistance through the administrator's Facebook contact and improved password-reset screens.
- Android push notifications for new events and attendance milestones, with device registration and schedule updates handled by the notification backend.
- Correct Student ID from Modify Students with a preview, administrator verification, duplicate checks and an audit trail. Existing passwords, contact email and student records are preserved.
- Super Admin Activity History for event changes, role changes, attendance corrections, password resets and ID corrections.
- Preview and recalculate saved Late/Present labels when changing a session's check-in cutoff. Manual corrections and original attendance times are preserved; existing fines need separate review.
- Stronger UID-based administrator verification and private-record access controls.
- Presence logos restored in login dialogs, live-status refresh improvements and bounded logout cleanup when network requests stall.

Install this APK over the existing Presence app; do not uninstall. It uses the existing package ID and signing identity. Allow notifications for phone alerts. Android settings, connectivity and background restrictions can affect delivery.

This is the existing signed beta distribution build with GitHub update support. Automated checks and build verification do not replace testing installation, camera, GPS and notification delivery on a physical phone.

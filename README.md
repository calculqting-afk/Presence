Presence


 Presence is a web and Android attendance management system that helps schools record student participation and manage school activities. It provides students and administrators with one place to access attendance records, events, announcements, surveys, and account services.

The main functions of Presence are:

- Account management: Students sign in to their accounts, while authorized administrators manage registrations, approvals, roles, and password recovery.

- Event management: Administrators create events, set attendance schedules, select participating students or sections, and assign attendance locations.

- GPS attendance: Students check in and check out during the scheduled times. When an event requires location verification, the system checks a fresh GPS reading against the assigned area.

- QR attendance: Students display their personal QR code. An administrator selects the event, scans the code, verifies the student’s identity, and confirms attendance.

- During attendance: Administrators can enable an optional checkpoint to confirm that checked-in students are still present during an event.

- Attendance records: Students view their attendance history, while administrators review participation, arrival status, and attendance reports.

- Correction requests: Students submit requests for attendance issues, and authorized administrators review and approve or decline them.

- Fines and community service: Administrators assign and manage attendance-related requirements. Students can view their requirements and progress.

- Event surveys: Administrators publish surveys for selected event sessions and review responses. Students answer available surveys and resume saved progress.

- Notifications: The system provides reminders and updates about events and attendance.

- Security and activity tracking: Account permissions control access to features, while administrative activity records help track important changes.

- Android updates: The app checks for new versions and lets users download and install available updates.

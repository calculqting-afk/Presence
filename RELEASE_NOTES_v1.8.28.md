# Presence v1.8.28

## What’s new

- Refreshed updater with clear installed and new version cards.
- Circular download progress and easy-to-follow update stages.
- Cleaner highlights, download details and action buttons.

## Installation

Install **Presence.apk** over the existing app, then reopen Presence. The current app handles this installation; the redesigned updater appears for future updates after installing this version.

This build preserves the existing signing identity for compatible in-place updates. Existing update checking, download verification and attendance behavior remain unchanged.

Android compilation, unit tests, artifact checks and APK package/signature/asset verification are performed before publication. Real-phone appearance and installation still need device testing.
